# fleet-watch (Fable rulings 399 + 401) — builder: fleet; refuter: eta-refuter-2

An OpenCode agent on a cheap Zen model (through a LOCAL read-only proxy) plus a deterministic wrapper watch every room. **The wrapper decides what is a problem; the model only gathers and explains.**

| piece | file | what it is |
|---|---|---|
| wrapper | `fleet_watch.py` | collects (read-only door), decides (item 5 rules), tracks state (one message per problem per state change, 60-min reminder, RESOLVED with duration, W21 flag), writes BUGLOG.md + jsonl + heartbeat on the Mini via ssh stdin, hsend to conductor, runs the model, enforces the $2/day budget |
| proxy | `scribe_fleet_mcp.py` | local stdio MCP "scribe-fleet": alone reads the read token; 4 tools only (scribe_rooms views list|now|fleet, scribe_system, scribe_health, scribe_sessions view list; `scribe_session_tape` refused ENTIRELY, r402); `include_*` refused; PER-VIEW FIELD ALLOWLISTS (`FIELD_SPECS`, generated by `gen_field_specs.py` from live field NAMES; anything else is dropped) plus a URL/host/signature VALUE scrub; logs the field names it passed (names only) to `~/fleet-watch/proxy-fields.jsonl` |
| config | `opencode.jsonc.template` | OPENCODE_CONFIG for the agent: NO remote Scribe MCP, NO Scribe token reference; tool allowlist; bash/edit/webfetch denied; title agent disabled |
| pane | `fleet-watch.sh`, `pane-run.sh`, `herdr-start.sh` | herdr WORKSPACE "fleet-watch" (own workspace, never a tab in another pane's); its pane tails the logs if the loop already holds the lock, else starts it; `MODE` file `dry` (default) / `live` |
| tests | `test_fleet_watch.py`, `test_scribe_fleet_mcp.py` | invented snapshots only; run `python3 -B test_*.py` |

Runtime dir `~/fleet-watch/` (off git): `bin/` (deployed copies), `opencode.jsonc`, `config.json` (optional overrides), `state.json`, `cost.jsonl`, `model-selection.jsonl`, `wrapper.log`, `dry/` (dry-mode outputs), `MODE`.

## Rules the wrapper applies (clinic hours 08:00-20:00 IST Mon-Sat, `config.json`; outside = INFO only)
- expected-recording rooms only (`expected_rooms`: OPD 1, 3, 4, 5, 6, 7, Cardiology OPD, ORB3); every other room is INFO ("known not-recording": Third Floor, Home Office, Dietary until V says otherwise).
- NOT_RECORDING; KIOSK_OFFLINE (reported instead of, not with, NOT_RECORDING); PIECES_STALLED (>10 min since the last piece while recording); TAPE_NOT_ADVANCING (level log: no advance for 10 min); EXACT_ZERO_TAPE (r343/r376: newest full 300 s chunk 707-709 B/s, from the session manifest, links dropped at once); DEVICE_MISSING; DEVICE_CHANGED; MIC_NOT_AUTHORIZED (ORB3 'unknown' configured OK); NOT_DELIVERING (>=10 min); DISK_RED (any hour, deliberately: a red disk is a problem outside clinic hours too).
- INFO only: quiet/near-silent levels (ZERO_SIGNAL from the level log; option E is withdrawn), DISK_AMBER, fleet health notes. Switches OFF is not a problem.
- `scribe_health` (a real whisper probe) at most every 15 min. Non-JSON / a dead door / a model error = a WATCHER fault (logged, heartbeat says ok=false), never a room problem.
- A room in a silence code (TAPE_NOT_ADVANCING, EXACT_ZERO_TAPE) for 20 min is flagged for the W21 self-test (the self-test is NEVER run from here).
