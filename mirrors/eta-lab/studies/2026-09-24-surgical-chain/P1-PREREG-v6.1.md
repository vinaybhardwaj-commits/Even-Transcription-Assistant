# SURGICAL-CHAIN-LINKER P1: pre-registration v6.1 (linker, 24 Sep 2026 18:10 IST): rulings 171-174 recorded; labels and link-3 may start

Addendum to `P1-PREREG-v6.md`; nothing earlier is edited. Source: Fable rulings 171-176 (`orders/RULINGS-FABLE-1835.md`, 18:35 review). **No label and no link-3 score existed when this was committed.** The label stage (`p1/build_chains.py` stage L, committed with this file) runs only afterwards.

- **Ruling 173, policy: "proposed-and-done" = A+, PROVISIONAL.** The proposed operation was done, possibly with more, or with part of a multi-item advice list. Label unit = (patient, advised name), earliest prescription kept (v5). Each label carries a `partial` flag (an advised item not covered by any done item; an extended match inside one item is not detectable by rule and is a stated limit). **B** (same indication, different technique) is stored as its own stratum (`technique_changed`) and **reported as a sensitivity number next to every A+ number**. If V picks B the labels are re-derived from the stored B stratum, with no re-run.
- **Ruling 171, contrast CT: in.** Plain and contrast CT are both in scope and the plain-CT rule (A7) already counts contrast studies; CT angiography stays referred out and advised-only (163). No change to the name rule.
- **Ruling 172, `conditional`.** "If it persists we will do a CT": a proposal status that is its own stratum, never a positive and never a negative. It is a status of the rated conversation (the surgery page and P2), not of a prescription-side chain; the builder has no field for it. Nothing in P1 links or labels changes; when P2 ratings carry it, `conditional` chains are reported apart.
- **Ruling 174, RXWIN cap.** v6 B1 (30 minutes plus the same doctor's next-visit cut) is confirmed as pre-registered before link 3; the count of windows the rules end early (256 of 1,096, 23%) is reported as its own number with every link-3 table.
- **Stage L output, fixed now:** the A+ label table (strata `A+ full`, `A+ partial`, `B only`, `mismatch`, `unknown`), the matched-negatives draw (seed 24; one N1 and one N2 per positive from the same doctor and ISO week; if none, the adjacent week with `borrowed = true`; no negative reused; shortfalls reported), and the link-3 worklist (visit window, doctor, day, route, tier, role, stratum). Link 3 itself is not run by this stage.
