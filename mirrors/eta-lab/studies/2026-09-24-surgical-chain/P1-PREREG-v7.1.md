# SURGICAL-CHAIN-LINKER P1: pre-registration v7.1 (linker, 24 Sep 2026; the git commit time is the timestamp): ruling 181, MRI referred out

Addendum to `P1-PREREG-v7.md`; nothing earlier is edited. Ruling 181 (V, relayed by Fable): MRI is not done at EHRC and is not in Metabase, so it is **referred out**, like CT angiography: **out of proposal scope, never a negative, never a done label, `offered_in_house = false` (hard-coded).** In the builder this is a name rule in stage D (`MRI`, `magnetic resonance`, `MR`) beside the CT-angiography rule, so any advised name that mentions it is `REFERRED_OUT` and a prescription whose named entries are all referred out is dropped from N1. **Checked on the frozen data before this commit: 0 of 633 advised prescriptions and 0 of 159 candidates carry an MRI name on the advised or the done side, so no count in any earlier table changes.** The plain-CT rule (A7) already excludes MRI orders.
