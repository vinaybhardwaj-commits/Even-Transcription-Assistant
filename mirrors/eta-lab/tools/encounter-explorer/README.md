# Encounter Explorer (M1: skeleton + adapter + synthetic fixtures + tests)

One HTML page, published later as a private claude.ai artifact. Three views on bare hash routes (`#overview`, `#list`, `#detail`); every other piece of state lives in JS.

## Three outputs from the same sources
Build outputs are not committed (`dist/` is ignored): `npm run build` writes the three pages below, and generates `fixtures/synthetic/mockup.json` first when it is missing.
- `dist/encounter-explorer.html`: **the live page**, `adapter-catalog` over the one tool `scribe_catalog` (actions search, get, clip_audio_chunk). `dist/capabilities.json` = mcp "Scribe MCP" [scribe_catalog] + sample, db, user (scopes profile); `dist/TOOLS.txt` lists the exact actions.
- `dist/encounter-explorer-mockup.html`: fixture adapter, synthetic dataset embedded (about 1.2 MB), declares only `sample`, `db`, `user` (`dist/capabilities.mockup.json`), never asks for `mcp`, banner "Mockup: synthetic data". Its synthetic Rx content stays (a mockup).
- `dist/encounter-explorer-current.html`: `adapter-current` over the older seven tools (`capabilities.current.json`, `TOOLS.current.txt`). Kept for reference only; not handed over.

## Files
- `src/types.js` JSDoc typedefs. `ConsultSummary` uses the catalog row's field names (consult_uid, ist_date, doctor_uid, room_id, t_open/t_close UTC ms, clip, layers, stages {state, reason}, first_gap "stage:reason", allowance, prescription, doctor_name, patient_name, individual_uid, prescription_uid, catalog_version, generated_at) plus extras (specialty, headline, lengthSec). `MIN_DATE` is 2026-09-09.
- `src/adapter.js` the one interface the UI uses: `listDays`, `listConsults`, `getConsult`, `getAudioUrl`, `notes.get/set`, `defaultRange`. Enforces the date floor, never throws (returns `{ok:false, code, message, retryable}`).
- `src/adapter-current.js` implementation over the current Scribe MCP tools; also `createNotes` (db doc `notes/{consult_uid}`). `src/adapter-fixture.js` same interface over `fixtures/mockup.json`; `src/audio-synth.js` WebAudio (OfflineAudioContext) tone track as a WAV blob, 15 min cap.
- `src/ui.js`, `src/style.css`, `src/template.html`, `src/main.js` page, tokens, wiring.
- `fixtures/synthetic/mockup.json` synthetic dataset from `scripts/gen-fixtures.mjs` (fixed seed, deterministic, generated on demand by build/test/check:data and NOT committed; two runs are tested byte for byte; all names are numbered placeholders such as "Synthetic Patient 0007", "Dr Synthetic ENT"): 4 fictional doctors x 10 IST days (2026-09-09..2026-10-13), 2-8 consults per doctor-day, pipeline levels from clipped-only to Rx linked, failed steps with reasons, Hindi/Kannada/English transcripts with English gloss. `fixtures/tools/*.json` come from `scripts/gen-tool-fixtures.mjs` (tool-shaped payloads for the mock Scribe MCP).
- `test/mock-scribe.mjs` a mock Scribe MCP over `fixtures/synthetic/tools` (node tests and the browser check).
- `build.mjs` writes both pages and the manifests.

## Switching the adapter
`src/main.js`, the `const impl = ...` line; the build constant `ADAPTER` is `catalog` (the live page), `current` or `mockup`, and `build.mjs` decides which constant goes into which file. Shared notes are db-backed in all builds.

## Assumptions to verify against real payloads
- `t0_ms`/`t1_ms` in `scribe_reb_index` are read as epoch ms when > 1e11, otherwise as an offset from IST midnight of the row's date. UNVERIFIED.
- Jev decision rows: key names are guessed (`question_id|question`, `answer|decision|value`, `probability|p|confidence`); unknown keys are ignored.
- `scribe_freescript` by `ist_date` is capped at 50 rows, and `scribe_rubric results` at 200; the grid flags "sources hit their row cap" when either is reached.
- Doctor identity is `pulse_doctor_uid`, else `doctor_uid8`, else the room. Names, patient names, transcript, audio, signed Rx and CDMSS are not in the current tools; those sections render "not available yet".

## Live catalog adapter (M2 round b; contract: scribe-mcp REPORT-CATALOG-1..6 and ORDER-CATALOG-7)
- `src/adapter-catalog.js` + shared `src/mcp-call.js`. **Search:** pages follow `next_cursor` with a repeated-cursor guard and de-dupe by `consult_uid`; `include_identity:true` is sent; the has-prescription filter is sent as `has_prescription` (server side, at most 31 days: a longer range gets guidance before any call); `identity_rows` 0 is shown as "not joined yet", never "no Rx"; `default_window` (last 30 days when no dates) is shown; blind room-days are reported.
- **Identity needs an admin token (C2).** A refused identity join (or `identity_unavailable`) is retried once as a plain read; after that names are hidden with a note, never asked again, and the has-prescription filter keeps working (it is read scope). A catalog that refuses `has_prescription` switches the filter off and says so.
- **Get** is called with `include_text:true` and `include_identity:true`. Layer `{status, source[], data}` becomes a panel state with its source and code; one failing layer never fails the call. Transcript: segment times are clip offsets in seconds (`t0_ms/1000`, t1 clamped to `duration_ms`); the player opens at `consult_span_ms.t0` and the span is marked on the transcript (outside lines dimmed); `degraded[]` tracks are named; `clock_mismatch` / `no_clock` layer errors get their own copy. Jev shows `calibrated_p` when stored, else the raw probability, and badges `mock` rows. Rubric score numbers only, verdict a short code. The ledger shows a time only where a layer has its own (rubric, jev); the catalog build time is never a step time.
- **Rx (palimpsest ruling):** the catalog copies no prescription content. The panel shows prescription id, `presc_state` and the tool's `pulse_url` (never rebuilt when the tool sent one; built from the two ids only when it did not), with "Signed prescription opens in Pulse".
- **Audio:** the artifact CSP blocks media from any other host, so there is no URL path at all (`clip_audio_url` is not called). Behind a feature check (`describeTool` action enum, else the first real chunk call: bad_args, unknown_action or a rejection there means "not available yet"), `clip_audio_chunk` is fetched sequentially (512 KiB per Fable C4, cache off, 64 MiB and 128 chunk caps, abortable on navigation, progress shown), assembled into a Blob and played from an object URL that is revoked on leave. Absent action: "Audio isn't playable inside the artifact yet; transcript timing still works". A click on a line before the audio is ready is queued. Bytes the browser cannot decode leave a message, never a dead player. `bad_range`, `read_failed` and `clip_not_found` are real errors with their own copy (never the not-available state). After assembly the page hashes the clip (crypto.subtle sha256) and the ledger says "Audio checksum matches catalog" / "does not match catalog" / "No catalog checksum" against `clip.audio_sha256` from the catalog row (the sha256 of the stored FLAC; a chunk answer carrying `audio_sha256` wins; `signature_sha256` hashes the cut-signature JSON and is never compared); it never blocks playback.
- Errors with designed copy: bad_args, not_found, catalog_unavailable (retry), bad_clip_key, blind_room_day, key_not_readable, identity_unavailable, too_many_matches, bad_range, unknown_action; a runtime `tool_error` rejection keeps the catalog code from the envelope on `e.result` (R5 S10).
- Tests: `test/adapter-catalog.test.mjs` over `test/mock-catalog.mjs` (shapes from the REPORTs) and the catalog flows in `browser-check.mjs`.
- UNVERIFIED: the exact stage names in `stages` (chips handle any names); the live admin-scope rejection shape (the page treats `admin`/`scope_or_tool_unavailable`/`needed` in the message or envelope as that refusal); `clip_audio_chunk` is specified (ORDER-CATALOG-7) but REPORT-CATALOG-7 did not exist when this was built.

**M2d (refute M2-1 fixes).** The list's Rx column is three-state (yes / no / "not joined yet" when the catalog sent `has_prescription: null`). The audio feature check never turns to "not available" once the schema or an earlier chunk confirmed the action, and only `unknown_action` or a `bad_args` naming the action sets it. Any non-retryable rejection of a call carrying `include_identity` is retried once plain; identity goes off only if that plain read works (no dependence on message text). A prescription that exists but whose ids are withheld reads "Prescription on file". `pulse_url` is trusted only on `https://pulse.even.in/`. A chunk longer than requested is refused. `layers_present` keeps only transcript/parts (no diarization panel). The ledger explains a dash in the Time column.
