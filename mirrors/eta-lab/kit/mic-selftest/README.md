# mic-selftest (rulings 368 + 369, INTERIM lab tool)
`python3 mic_selftest.py <opd3|opd4> --room-state state.json` proves a room mic hears sound with nobody in the room. Stdlib only; run from the Mini.
- **Default is a plan** (no network). `--check-only` (read-only preconditions on the Mac) and `--live` both need `--fable-order "<the named order>"` and a committed, pre-registered `calibration.json`; no calibration, no run.
- **Sound played** with afplay at the Mac's current volume: [3 chirps 1-3 kHz] [0.5 s] [canary word, `say -v Rishi -r 150`, rendered once = `canary.wav`, sha pinned] [0.5 s] [3 chirps]. Nothing else runs on the Mac (`afplay date tail stat pgrep scp`, `rm` of our own /tmp wav; never python3).
- **Preconditions:** interlock (exactly one `tapewriter record`, its `--out` path contains the room's `recording_session_id` as a directory name: two Macs are named EHRC-CONSUL4), recording and not paused, 1 live run/room/hour, no speech-level second in the last 5 min, and in clinic hours the room must read **dead** (every 1 s frame of the last `dead_window_s` <= `dead_rms_max`).
- **Calibration:** on TAPE, never the level log. `tape_stats.py` (run on the box) reduces lab-mover's chunks to per-second RMS numbers; `calibrate.py` turns labelled stretches (empty / quiet / used / unlabelled) into a threshold: 120 s windows, level = their 90th percentile, `dead_rms_max` = 1.10 x the highest level in any empty stretch, and it refuses if the rule would fire in more than 2% of an occupied stretch's windows. It writes `proposed` unless `--preregister` (needs an occupied ground-truth stretch); commit the `preregistered` file BEFORE any live run: that is the pre-registration. `calibration-proposal-20260925.json` is today's PROPOSAL, not yet a pre-registration.
- **Result (a), acoustic, now:** `detected`, `snr_db`, `lag_ms`, `ncc_peak`, `rms_before/during/after`, `speech_band_ok` (word 300-3400 Hz vs chirp band). One JSON line per run in `scratch/mic-selftest.jsonl`, with the exact tape interval (`selftest_epoch`, `tape_from_byte`, `tape_to_byte`, `session`).
- **Result (b), STT, deferred:** `stt_result(text, engine, language)` fuzzy-matches the canary (phonetic skeleton, edit-distance ratio >= 0.6; Latin and the nine Indic scripts, transliterated). Pass on (a) + miss on (b) = STT/routing fault, not the mic.
- **Never in a patient record:** `selftest_filter.filter_segments(segments, load_intervals(log))` drops segments within `FILTER_MARGIN_S` (5 s) of a run's interval or matching the canary, and FAILS CLOSED (no times, no room, unreadable log). Dropped items carry no text and show as 'mic self-test'. `selftest_annotation_items(log)` feeds the vault's `selftest` kind.
- **Assumptions to confirm:** session id is a path component of the segment dir; `scribe_rooms` fields `recording`, `paused`, `recording_session_id`; clinic hours (unset = always clinic).
- **False positives:** `null_distribution.py` on 200 white + 100 band-limited noise seeds: max peak 0.016 / 0.032 vs threshold 0.15, 0 at or above (`null_distribution-20260925.json`).
- Tests (offline, synthetic PCM, ~130 s): `python3 -B -W error::ResourceWarning -m unittest test_mic_selftest test_selftest_filter test_calibrate test_tape_stats`
