# Medication-note bench — pre-registration (W27.7b, rulings W30.3, 27 Sep 2026)

Fixed BEFORE any live Jev call. Changing anything below after the first live run makes it a different bench; say so in the report.

- **Question under test:** U4 `note_sentence_supported` at `jev-note-safety-v1`, exactly as production registers it (state `{transcript_excerpt}`, one noul per sentence, 4 sentences per call).
- **Data:** generated by `generate.ts`, seed `notesafe-med-bench-v1`, 100 truth lines per split (dev, test), each with 1 invented transcript and 4 sentences (2 supported, 2 perturbed) = 800 sentences, 400 supported. All text invented (D1a); formulary is vocabulary only; CAP-1 scored_items (sha 54dca57d) informed the drug list (26 distinct drug terms), no consult text is used. Real transcripts never go to Jev (D1b).
- **Labels:** by construction. Perturbed = the truth line with ONE change against an unchanged transcript: dose (alt strength / decimal shift / mg-mcg), number (frequency / duration / tablet count), drug (look-alike / same-class / random). Per split exactly 80 dose, 60 number, 60 drug. Test suite pins the invariants (change visible in the sentence, swap target never the distractor drug).
- **Split:** BY DRUG. A drug never appears in both dev and test.
- **Flag rule:** flag iff P(supported) < T. T = the largest of {0.05..0.95, step 0.05} with DEV false-flag <= 8%, else 0.05. T is frozen; TEST is scored once at that T.
- **Primary metric:** test false-flag = P(flag | supported). **PASS** iff observed <= 10% AND one-sided 95% exact (Clopper-Pearson) upper bound < 25%. Any unanswered sentence withholds PASS (absent is not "supported").
- **Secondary (reported, no target until first read):** catch rate overall and by perturbation type; false-flag on the codemixed, brand_generic and abbrev subsets; accuracy and ECE (`lib/jev/bench.ts`).
- **What it does not prove:** invented text is cleaner than room audio; this is a FLOOR on false-flag. The real-data read remains the shadow-week `jev_decision` sample.

Run: `generate` -> `run` (real Jev; ETA_JEV_ENABLED=1, TYPESAFE_API_KEY from the caller's env) -> `score`. `selftest` exercises the whole path on a mock oracle with no network.
