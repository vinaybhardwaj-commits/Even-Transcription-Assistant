Install and fleet — the three row changes Build R3 makes

This file shows only what changes. It is a delta on the approved mockup of 7 September, and it copies that file's tokens and class names exactly, so the two read as one design.

Two of the three changes are not new design. The approved mockup already shows an idle room's tape as "idle, no session" and already carries a channel tag. The shipped code does neither. R3 restores them. The one genuinely new thing is the update failure line, and states C and D offer two places to put it.

State AThe correction. A room with the app running and no patient in it. Today the shipped card raises "Tape not advancing. The room is not putting audio on the day tape." on this row, because deriveRow tests only tape_advancing and never asks whether a session is open. Home Office carries that warning right now while it is healthy. R3 adds a session_open poll field, and the row reads what the approved mockup always said it should read.
