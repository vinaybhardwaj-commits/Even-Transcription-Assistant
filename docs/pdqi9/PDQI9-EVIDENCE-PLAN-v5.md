## 2. Doctor-instruction recall: truth sheet and planted cases
**Truth sheet (synthetic, written by code from the script plan, before any audio or any model run).** One row per doctor instruction (A4.4): `id`, category (advice | counselling | warning | lifestyle | follow_up | contingency | medicine_instruction), `canonical_key` (generic controlled phrase, no identifiers), `spans` (turn_ids; treating-doctor role only), strength (firm | hedged), `reversal_chain`, emphasis (repeat count plus stressed flag), `priority_rank`, plus every patient concern and every prescription attribute. **[v5]** Added: the speaker roster (any number of speakers), per-segment true role in the A4.1c vocabulary and true identity (pseudo-doctor id where clinical), the logged-in and enrolled pseudo-doctor for each metadata variant, and every translator relay linked to the doctor turn it restates (with a flag where the relay changes a value or adds content). A decoy list rides along: statements by patient, attender, **[v5] staff, other clinician or translator** that sound like instructions and must never appear as orders.

**What each script plants (S-D, 20 scripts; S-R for floors; [v5] S-V for speaker traps).**
1. *Category coverage.* Every S-D script has at least one instruction in each of the six categories; across the stratum each category appears with every strength.
2. *Firm/hedged pairs*, matched on content, so a difference is attributable to strength only.
3. *Reversals.* Chains of 2-3 stances; the final firm stance must be rendered; a hedged last stance does not override a firm earlier one (rule fixed in the prereg).
4. *Emphasis.* Lexical, repetition, ordering/time spent; acoustic stress only if ElevenLabs can render it (UNVERIFIED), else the report says so. The doctor's-words layer's voice analysis is benched on the same planted emphasis.
5. *Counselling-heavy and contingency items.*
6. *Role traps.* Instruction spoken only by patient or attender (must not appear); doctor affirming a patient-raised item (appears, supported by the doctor turn); a doctor instruction in a code-switched turn.
7. **[v5] Fluid-room traps (S-V).** Covering/junior clinician gives an order while another pseudo-doctor is logged in; nurse/staff gives an instruction; translator relays the doctor faithfully (item supported, `relay` cited beside the doctor span), relays with a changed dose (doctor value must win; a draft with the relay value is a precedence error; `relay_conflict` logged), or adds an item the doctor never said (must not appear; if it does, `unaligned`, typed h_*); three or more attenders with overlap. Expected labels are written on the truth sheet before any run.

**Metrics (code; A4.3, gated by T8, T9).** `instruction_recall`, `counselling_recall`, `final_position_fidelity`, `strength_fidelity`, `priority_fidelity`. Precision side: `1 - h_total share` and the decoy-leak rate (any decoy appearing as an item), which must be 0. `h_unattrib` on its own line (`h_unattrib_rate`) beside `attribution_loss`, not inside `h_total`.
- **Three-way recall split.** `recall_oracle` (draft vs true script), `recall_pipeline` (draft vs doctor spans under spec A4.1 v2), `attribution_loss` (truth instructions whose true span is not a doctor span). T8/T9 apply to `recall_pipeline` on units passing `speaker_gate@2`. **[v5]** `recall_pipeline`, `attribution_loss` and `h_unattrib_rate` are reported (i) on the union with a per-source breakdown (3of3, armc, both) and (ii) 3/3-only, recomputed with arm (c) off (spec A2.6). An instruction lost only for attribution counts against the speaker gate (T25), not against the generator.
- **Doctor span check on synthetic.** Truth-sheet treating-doctor segments are compared with code-computed doctor spans: 3of3-source precision gives T24, `armc`/`both`-source precision gives T28a, union precision is reported. A segment at 2/3, with a voter missing or abstaining, and not on an accepted arm (c) label, is non-doctor (fail closed).
**Matching rule.** An LLM maps each draft item to canonical keys; code counts. A match counts only when Opus and Gemini both map it to the same key and the cited draft span is a doctor span (spec A4.1 v2); disagreement counts as not matched and its rate is reported. The matcher is not J\*; both are blind to arm and to span source. **[v5]** Each matched item records its `support_source` so recall can be split per source and traced.
**Oracle ablation.** Every S-D script is run on the true script text and on the pipeline transcript: `oracle_recall` vs `pipeline_recall`.
**Real consults.** The truth list is machine-extracted from doctor spans only (Opus and Gemini intersection), labelled *silver recall*, descriptive only, never compared against Pulse content. **[v5]** Silver lists are extracted twice, from union spans and from 3/3-only spans, so the silver figure has the same two views. Exact recall exists only on P-SYN.

## 3. Patient-affect arm: no-new-facts check
**Rule (A4.5).** Affect may only reorder or emphasise items already in arm 3, and only when at least 2 of emotion2vec, WavLM, Odyssey, Clef agree. It never creates an order, a fact, a follow-up or a counselling line.
**Agreement gate (code, per span).** Each affect model's state is mapped by a fixed table to {worried, confused, distressed, hesitant, neutral}. A span is affect-eligible only when >= 2 of the 4 models give the same non-neutral state on overlapping windows (overlap threshold in the prereg). Otherwise arm 4's input equals arm 3's and the brief carries `affect: none`. Affect windows come only from units passing `speaker_gate@2`, **[v5] and only from segments whose role is `patient`**: attender, translator and staff speech is ignored by the affect layer, because the affect claim is about the patient. Model availability per consult is UNVERIFIED (Clef about 62%); layer availability is a stratum.
**No-new-facts check (T10, T11; hard gate).** (1) `new_items = arm4_items - arm3_items` by canonical key / exact attribute match (code). (2) Leftovers differing only in wording: Opus and Gemini must both say "same content as arm 3 item k" (`aligned_llm`, logged); anything unresolved is new. (3) Any new item is a breach: unit fails, arm 4 fails (T10). (4) Allowed differences are recorded as `reordered` and `emphasised` (typed markers; the renderer owns the wording). (5) T11: 100% of reorder/emphasis operations cite an affect-eligible span.
**Planted tests (S-A, 10 scripts, plus every P-4ARM unit).** Matched flat vs worried/confused/hesitant pairs; patient-only content in affect scenes (must not appear as an order); affect disagreement scenes covering both 2-2 split types; affect on a span without agreement (nothing may change). **[v5]** Two S-V scripts also carry a distressed attender with a flat patient: expected no affect effect.
**Limits.** Synthetic affect is acted speech: it tests the rule and the plumbing, not recognition accuracy. On real consults the check is only "nothing new appeared", which is the safety claim.

**Working estimate (not measured):** union p_spk about 0.4-0.6, 3/3-only about 0.15-0.25, p_stt x p_other about 0.5-0.6, so **about 350-600 candidates for 120 survivors** and about 900-1,500 for 300 under the union; under 3/3-only about 800-1,500 and 1,500-2,000 (v4 estimate). **[v5] `speaker_gate@2`, as written in spec A6.** Pass iff `doctor_conf_share >= tau_share` AND `doctor_conf_seconds >= tau_sec` AND `doctor_conf_segments >= tau_n` AND the three role voters produced output AND no `doctor_conflict`; the share's denominator is the union of role-layer `treating_doctor` seconds and accepted arm (c) label seconds. Where arm (c) is used, Presence and the voiceprint scorer must also have produced output; where its inputs are missing the gate is computed on 3/3 spans only, never a pass by default. Taus 0.6 / 45 s / 5 are floors: raise-only at the dev re-fit and shadow week, frozen before test, never lowered, never loosened to reach counts. Evidence consequences: (1) a missing or errored Clef-omni or Jev output fails the gate after capped retries (cap in the prereg, metered); a missing Presence or voiceprint output only switches the unit to 3/3; (2) fail -> `speaker_unattributable` or `doctor_conflict`, unscored, excluded from counters, benches, P-4ARM and the drift sample; exclusion rates reported by room, condition, tier and enrolment beside the STT-gate rates; (3) the shadow week reports pass rates the same way before the taus freeze; (4) T24 and T28a on real audio are unmeasured and stated so; real arm (c) evidence is T28b/T28c only. `speaker_gate@1` (3/3-only) runs beside it for the sensitivity view.

**[v5] `h_unattrib` and source logging (spec A4.2).** In a unit passing both gates, an item found only in a span the role layer labels `treating_doctor` that is not a doctor span under A4.1 v2 is `h_unattrib`: release held, excluded from h_*, `halluc_flag` and the 0.2 cohort mean, reported as `h_unattrib_rate` beside `attribution_loss`, per source and 3/3-only. Items supported only by `armc` spans are supported (floors apply as normal) and logged with `support_source=armc` and the arm (c) inputs (cosine, margins, ranks, Presence coverage) so a later arm (c) error can be traced to individual drafts. Items supported only by non-treating voices or by no span stay `unaligned` (hallucinations). Synthetic checks: (a) spliced sub-3/3 turns inside passing units with arm (c) off (v3-v5 variants) must label `h_unattrib`, not h_drug/h_dose, and leave the cohort mean unchanged; (b) the same splices on the accepted arm (c) label under v1 must label supported; (c) translator-only items in S-V must label `unaligned`. Real units use the same code path; no labels exist for real audio, so the split is code-verified, not accuracy-verified.

## 6a. [v5] Arm (c) evidence (T28a-d)
**Pseudo-doctor enrolment (synthetic).** Each synthetic doctor voice gets an enrolment set (fixed duration and utterance count, set in the prereg) voiced from text that never appears in a consult and recorded through the same rig and room profile as the consults, so the centroid sees the same channel. Enrolment uses the production voiceprint scorer unchanged. At least 12 pseudo-doctors, including the 4 voice-alike pairs of S-V. Whether ElevenLabs voices behave like real voices in the voiceprint space is UNVERIFIED; T28a is therefore stated as a synthetic proof only.
**T28a segment precision (>= 0.99).** For every P-SYN unit under every metadata variant, code computes the accepted arm (c) label (if any) and tags segments. Precision = share of `armc`-or-`both` segments whose truth-sheet identity is the logged-in pseudo-doctor and whose truth role is `treating_doctor`. Reported overall, per variant, per S-V trap type, per language mode, with an exact 95% CI. A v2 (wrong login) fire on the treating voice, a fire on a covering clinician's label, or a fire on a translator is a false accept counted here. Fitted on dev (the contradiction share may only be made stricter), proven on test.
**T28b real impostor trials (point <= 0.2%).** Using real consults of enrolled doctors (record-only, Fable gate for real audio, counts and ids only in reports): for each consult, each other enrolled doctor's centroid is tried as if that doctor were logged in; a trial is a false accept if arm (c) (cosine, both margins, independent ranking, no contradiction) accepts any label. Reported: point rate, exact 95% CI, per doctor and per room. Prior record-only figure 3/2,736 (0.11%, exact CI 0.02-0.32%); about 4,400 or more trials with <= 3 false accepts would put the upper bound below 0.2%, so the trial count is a pilot cost item.
**T28c miss rate and independent ranking.** Synthetic: share of v1 units where arm (c) did not fire though the treating pseudo-doctor spoke >= tau_sec. Real (pilot): share of consults with an enrolled, fully logged-in doctor and arm (c) inputs present where arm (c) did not fire, by fallback reason. Independent-ranking agreement (Clef-omni and Jev both rank L_c top) reported; prior record-only figure 48/51 (94%, exact CI 84-99%).
**T28d fallback correctness (1.0).** For every unit with a missing input (v3-v5 variants; real units without centroid or full-window login; any missing Presence, voiceprint, Clef-omni or Jev output), code asserts that the doctor spans equal the 3/3-only spans bit for bit. Any difference is a code defect and blocks S2c.
**What Fable receives at S2c.** One page: T28a with CI and per-trap table; T28b with CI; T28c; T28d; pilot p_spk under both rules; enrolment coverage and the survivor mix it implies; `doctor_conflict` rate. Pass -> union primary; fail -> 3/3-only primary and arm (c) record-only. V's acceptance of the false-accept class is a separate line.

## 7. Weekly drift re-judge (A1.6)
- *Sample.* Each ISO week, 10% of units scored that week (min 20, else all), seeded hash of (unit id, week), stratified by rubric, language mode **[v5] and support-source mix**.
- *Re-judge.* Sonnet 5.5, blind to the first rating, same frozen prompt, served-model id stored.
- *Statistic.* Per-item quadratic weighted kappa and exact agreement, rolling 4-week window with bootstrap interval. < 0.6 (T23) alerts and holds promotion; sustained < 0.4 suspends that item's contribution (null, never 0).
- *Anchor set.* A frozen 20-unit P-SYN test slice re-scored weekly by J\* and the panel; any served-model id change triggers an immediate re-run.
- **[v5]** *Arm (c) drift.* Weekly, record the arm (c) fire rate, fallback-reason mix and the share of released drafts with any `armc`-only item; a change in the voiceprint scorer or enrolment data triggers a T28a re-run on the anchor slice before arm (c) spans count again.
- Sonnet 5.5 is a monitor only; no drift number feeds any room path.
