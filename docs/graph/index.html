How to use the views

Overview map →Every cluster of closely related code is a bubble; lines show which clusters talk to each other. Click a bubble to read what is inside; drag to rearrange, scroll to zoom. Folder tree →Open folders like in a file explorer, down to single files and functions. Click a function to see what it connects to. Full report →Auto-written analysis: most-connected pieces, surprising links, every cluster. Raw data ↓graph.json (gzip, 4 MB) for engineers and AI tools. Unzip, then load with graphify or any JSON tool.

Good to know

  • Two edge counts: "links" (156,160) counts every connection; "unique edges" (151901) counts each pair of things once. The report pages use the unique figure.
  • Tree total: the folder tree shows 48,882 items rather than 55,723. It lists only items that belong to a file in the repo; it leaves out docstring notes, concept nodes and outside libraries such as next.
  • Cluster names are automatic (folder + the two best-connected pieces), not hand-written.
  • This is a code-only graph: documents and SQL migrations are not analysed.
  • The mirrors folder holds copies of sibling projects, so a large share of the graph belongs to them.
  • Rebuilt from main by rebuild.sh; always check the commit shown above for freshness.
